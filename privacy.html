Privacy policy

Effective November 15, 2026 · Dusk 0.2.0

Dusk changes the appearance of web pages to a dark palette. Its page processing and preferences stay in your browser. The extension does not send them to the developer or to third parties.

What Dusk handles

To change page appearance, Dusk inspects page elements, computed styles, colors and layout, including embedded frames and web components. It temporarily keeps references to elements and their original styles in memory so it can restore them when you turn Dusk off. It does not save copies of page content or take screenshots.

When you open the popup, Dusk reads the active tab’s URL to identify the site and show its controls. On pages, it uses the hostname to apply your site preference. It does not keep a browsing history, visit timestamps, full URLs, query strings or page titles.

Dusk responds to page changes, pointer and keyboard events, focus changes, input events and resizing to update colors. It does not record keystrokes, text entered into forms, pointer coordinates or an interaction history. It does not read password values, cookies or authentication tokens.

Dusk reads the browser’s preferred interface language and the system light/dark preference. These are used locally to choose the interface language and follow the system theme.

What is stored

Dusk uses chrome.storage.local to store your global mode (System, On or Off) and explicit site exceptions. Each exception contains a hostname and an on/off choice. Local files share a single local-file preference; file paths are not saved. These settings are not sent to a Dusk account or server and do not use Chrome’s synchronized storage.

Preferences remain in the browser profile until you change or remove them. Choosing Default for a site removes that site’s exception. Uninstalling Dusk removes its extension storage from that profile. Temporary page state is released when the page or tab is closed. Browser or device backups are controlled by your browser and operating system.

Why these permissions are needed

  • Page access: Dusk’s bundled scripts run on HTTP and HTTPS pages, including frames, so dark appearance can apply automatically as pages load. Local file access works only if you enable it in the browser’s extension settings.
  • Storage: remembers your mode and site exceptions locally.
  • Active tab: identifies the current site when you open Dusk’s popup, so you can control that site.

You can restrict Dusk’s site access, disable it or uninstall it through your browser’s extension settings. Browser-protected pages cannot be recolored.

No analytics, advertising or remote code

Dusk has no analytics, telemetry, advertising SDKs, remote scripts or developer-operated backend. Its code is included in the extension package. It makes no network requests to transmit page data or settings. It does not sell, share or use this data for advertising, profiling, credit decisions or lending. The developer cannot remotely view your pages or preferences.

Limited Use

Dusk’s use of information received from browser and Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide Dusk’s dark appearance and its user-facing controls.

This website and support

This policy website has no analytics, tracking scripts, forms or external fonts. It is hosted on GitHub Pages. GitHub may process technical request information, including IP addresses, under its privacy statement. Visiting this website is separate from using the extension; Dusk does not automatically contact it.

You can contact the maintainer through the solo-s GitHub profile. Information you choose to submit on GitHub is handled by GitHub and may be public. Do not include passwords, private page content or other sensitive information in public reports.

Changes

This policy describes Dusk 0.2.0. If its data handling changes, this policy and the store disclosures will be updated. The effective date appears above.

Политика конфиденциальности

Действует с 15 ноября 2026 года · Dusk 0.2.0

Dusk меняет оформление веб-страниц на тёмное. Обработка страниц и настройки остаются в браузере. Расширение не передаёт их разработчику или третьим лицам.

Какие данные обрабатываются

Для изменения оформления Dusk анализирует элементы страницы, вычисленные стили, цвета и размеры, включая вложенные фреймы и веб-компоненты. Ссылки на элементы и исходные стили временно хранятся в памяти, чтобы восстановить оформление после выключения. Копии содержимого страниц не сохраняются, скриншоты не создаются.

При открытии панели Dusk читает URL активной вкладки, чтобы определить сайт и показать его настройки. На страницах используется имя хоста. Расширение не ведёт историю посещений и не сохраняет время посещения, полные URL, параметры адреса или заголовки страниц.

Dusk реагирует на изменения страницы, события мыши и клавиатуры, смену фокуса, ввод в поля и изменение размеров, чтобы обновлять цвета. Нажатые клавиши, введённый текст, координаты указателя и история действий не записываются. Значения паролей, cookies и токены авторизации не читаются.

Язык интерфейса браузера и системная светлая или тёмная тема используются локально для выбора языка панели и режима «Система».

Что сохраняется

В chrome.storage.local сохраняются общий режим («Система», «Вкл.» или «Выкл.») и явно заданные исключения для сайтов: имя хоста и выбор включения или выключения. Для локальных файлов используется одна настройка local-file; пути файлов не сохраняются. Настройки не передаются в аккаунт или на сервер Dusk и не используют синхронизируемое хранилище Chrome.

Настройки остаются в профиле браузера, пока вы их не измените или не удалите. Выбор «Как везде» удаляет исключение для текущего сайта. Удаление Dusk удаляет его хранилище из этого профиля. Временные данные страницы освобождаются при её закрытии. Резервными копиями браузера и устройства управляют сам браузер и операционная система.

Для чего нужны разрешения

  • Доступ к страницам: встроенные в расширение скрипты работают на HTTP- и HTTPS-страницах, включая фреймы, чтобы автоматически применять оформление при загрузке. Доступ к локальным файлам работает только после вашего включения в настройках расширения.
  • Хранилище: запоминает режим и исключения локально.
  • Активная вкладка: позволяет определить текущий сайт при открытии панели Dusk и управлять его режимом.

В настройках расширений браузера можно ограничить доступ Dusk к сайтам, отключить или удалить его. Защищённые страницы браузера перекрашивать нельзя.

Без аналитики и удалённого кода

В Dusk нет аналитики, телеметрии, рекламных SDK, удалённых скриптов или сервера разработчика. Код поставляется в составе расширения. Dusk не выполняет сетевые запросы для передачи данных страниц или настроек, не продаёт и не передаёт эти данные и не использует их для рекламы, профилирования или кредитных решений. Разработчик не может удалённо просматривать ваши страницы или настройки.

Ограниченное использование

Использование Dusk информации из API браузера и Google соответствует Chrome Web Store User Data Policy, включая требования Limited Use. Данные используются исключительно для тёмного оформления и его пользовательских настроек.

Этот сайт и поддержка

На сайте политики нет аналитики, отслеживающих скриптов, форм и внешних шрифтов. Он размещён на GitHub Pages. GitHub может обрабатывать технические сведения о запросах, включая IP-адреса, согласно своей политике конфиденциальности. Посещение этого сайта отдельно от работы расширения: Dusk не обращается к нему автоматически.

Связаться с автором можно через профиль solo-s на GitHub. Добровольно отправленные через GitHub сведения обрабатываются GitHub и могут быть публичными. Не публикуйте пароли, содержимое приватных страниц и другую чувствительную информацию в открытых обращениях.

Изменения политики

Политика описывает Dusk 0.2.0. При изменении обработки данных политика и сведения в магазине будут обновлены. Дата начала действия указана выше.
